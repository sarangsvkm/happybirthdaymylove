# happybirthdaymylove ❤️🎂

A special, beautifully animated Birthday Surprise web application made with React, Vite, Tailwind CSS, Framer Motion, and Lucide Icons.

## ✨ Features
- 💌 Interactive Birthday Card & Countdown
- 📸 Photo Memory Gallery with interactive polaroids & lightbox
- 🔐 Secret Love Vault with playful passcode protection
- 🎈 Floating Balloons, Confetti, and Music playback
- 💫 Smooth animations and responsive romantic design

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
